# Дизайн-система публичной витрины (T-50)

Источник правды по внешнему виду витрины. Вид меняем здесь, в `tokens.css`, а не в разметке
страниц: иначе каждая новая шаблонная страница (а в релизе их сотни тысяч) переизобретает
оформление заново.

## Что где

- `index.css` — точка входа. Страница подключает один этот файл, он тянет шрифт, токены
  и компоненты в правильном порядке.
- `tokens.css` — палитра, шкала размеров, плотность, скругления. Один файл, от которого
  зависит всё остальное.
- `components.css` — словарь классов, из которых собираются страницы витрины. Правило то же,
  что у токенов: вид меняем здесь, а не в разметке страницы.
- `fonts/` — Onest. Лежит локально и раздаётся со своего домена: файл вариативный, один woff2
  на подмножество символов покрывает всю шкалу 400—700.
- `preview.css` — каркас карточек самой дизайн-системы. В вёрстку витрины не уезжает.
- `components/*.html` — самодостаточные превью компонентов. Каждый показывает все состояния,
  включая «нет данных»: часть каналов приедет без метрик.

Первая строка каждого превью — маркер `<!-- @dsCard group="..." -->`. По нему на `claude.ai/design`
собирается карточка компонента. Группы: `Основа` (палитра, типографика) и `Компоненты`.

Выгрузка на `claude.ai/design` собирается командой `node .design-sync/build.mjs`; что и почему —
в `.design-sync/NOTES.md`.

## Курс (решения PO 28.07)

- расположение элементов своё, стилевые приёмы взяты у BidFox: плоский белый список без теней,
  цветной бейдж-скоринг, метрика «серый лейбл сверху, значение снизу», высокая плотность;
- **уходим с синего акцента.** У BidFox тот же `#2f6fed`, что был у нас. Витрина идёт не под брендом
  WOWBlogger, выглядеть клоном конкурента ей незачем. Акцент — приглушённый тил `#0d6e63`;
- тёплый небелёный фон страницы `#faf9f7`, чисто белые строки поверх. Причина утилитарная: меньше
  усталости глаз на длинных списках;
- границы вместо теней;
- насыщенный цвет только на плашке «реклама» и на скоринговом бейдже;
- шрифт Onest.

## Чего в системе нет намеренно

- **Денег.** Ни цен, ни CPV, ни CPM, ни CPA, ни себестоимости (решение PO 27.07). У BidFox цена
  размещения стоит правой колонкой — это цены маркетплейсов-конкурентов, ровно то основание, по
  которому зарубили демографию.
- **Табов.** Ни по площадкам автора, ни по постам (решение 27.07). Площадки — ссылки на отдельные
  страницы, у каждого канала свой URL.
- **Демографии.** Перепубликация данных конкурента (решение 22.07).
- **Блока «это ваш канал»** и заявок от владельцев: разбирать их некому (решение 22.07).

## Хвосты

- **Наполнение скорингового бейджа не решено.** Форма есть, что показывает цифра — отдельный вопрос.
- **Прототип на дизайн-систему не переведён.** В `prototype/style.css` осталась старая вёрстка
  с синим акцентом и тенями. Пока это два независимых источника вида, и расходятся они молча.
- **Логотип и название — заглушка:** домен за Максимом, на 22.07 не куплен.
