{# Колонка фильтров. Форма отправляется методом GET, то есть каждое состояние получает свой адрес — иначе фильтр нельзя ни переслать, ни открыть в новой вкладке, а без клиентского кода ещё и нельзя удержать при переходе на следующую страницу. Разметки две, и это не дублирование по недосмотру. На десктопе колонка стоит раскрытой, на телефоне свёрнута — атрибут `open` у `details` один на всех и медиазапросом не переключается, поэтому вариантов ровно два: клиентский код (запрещён) или две разметки, каждая скрыта на чужой ширине. Лишний килобайт дешевле скрипта. Идентификаторы полей поэтому разведены суффиксом. #} {# Чип колонки (T-158). Адрес с `?cat=` закрыт в robots.txt, и ссылка на него только жгла бы обход: Google идёт по `href`, упирается в запрет и копит адрес в «Заблокировано в robots.txt». Такой чип — кнопка пустой GET-формы `form` (своя у каждой копии колонки): путь в `formaction`, тематика полем `cat`. Браузер собирает из них тот же адрес, что был у ссылки; значение сырое, кодирует его браузер. Чип на открытый адрес остаётся ссылкой: по ним идёт индексация. #} {% macro chip(path, cat, on, form) %}{% if cat %}{% else %}{{ caller() }}{% endif %}{% endmacro %} {# Чип тематики внутри раздела площадки. У пары «площадка + тематика» с T-83 есть собственная страница, но только если каналов в ней хватает на непустую выдачу; у остальных пар тематика остаётся параметром, и чип становится кнопкой. Список пар приезжает готовым из дампа — считать здесь нечего. `caller()` сохраняется заранее: в `call` внутри макроса он уже чужой. #} {% macro cat_chip(section, slug, landings, on, form) %}{% set label = caller() %}{% if not section %}{% set path, cat = '/category/' ~ (slug | urlencode), none %}{% elif (section, slug) in landings %}{% set path, cat = '/category/' ~ (slug | urlencode) ~ '/' ~ section, none %}{% else %}{% set path, cat = '/' ~ section, slug %}{% endif %}{% call chip(path, cat, on, form) %}{{ label }}{% endcall %}{% endmacro %} {# Путь города (T-137): площадка текущей страницы сохраняется, тематика едет полем кнопки, диапазоны и сортировка сбрасываются, как у чипов площадок. #} {% macro city_path(slug, section) %}/city/{{ slug | urlencode }}{% if section %}/{{ section }}{% endif %}{% endmacro %} {% macro filter_form(base_url, filters, section, suffix, categories_visible, categories_rest, selected_category, landings, cityf=none) %} {% set chips = 'chips-' ~ suffix %}
