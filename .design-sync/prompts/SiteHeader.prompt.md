Шапка сайта: логотип и навигация, вторым рядом — разделы по площадкам, ниже заголовок страницы с абзацем текста.

## Разметка

```html
<header class="hdr">
  <div class="inner">
    <a class="logo" href="/"><span class="logo-mark">Б</span> Блогеры России</a>
    <nav class="nav">
      <a class="on" href="/">Каталог</a>
      <a href="/collections">Подборки</a>
      <a href="/topics">Тематики</a>
    </nav>
  </div>
</header>

<div class="sections">
  <div class="inner">
    <a class="sec on" href="/">Все площадки</a>
    <a class="sec" href="/telegram">Telegram</a>
    <a class="sec" href="/vk">ВКонтакте</a>
  </div>
</div>

<div class="hero">
  <h1>Каталог блогеров и каналов России</h1>
  <p>24 615 каналов во всех соцсетях: подписчики, охваты, вовлечённость и доля
  рекламы в ленте. Данные обновляются ежедневно, поиск и фильтры бесплатны.</p>
</div>
```

## Из чего состоит

| Класс | Что это |
|---|---|
| `.hdr` + `.hdr .inner` | верхняя полоса, 60px, содержимое по `--wrap` |
| `.logo` / `.logo-mark` | название и квадратный знак в акцентном цвете |
| `.nav` / `.nav .on` | навигация справа; `.on` — текущий раздел |
| `.sections` + `.inner` | второй ряд, 46px, прокручивается по горизонтали |
| `.sec` / `.sec.on` | раздел-пилюля; `.on` — выбранный |
| `.hero` | заголовок страницы и абзац под ним |

`.inner` внутри `.hdr` и `.sections` центрирует по `--wrap` — тот же приём, что
в `.ds-wrap` для остального содержимого страницы.

## Правила

- Разделы — вторым рядом, а не в выпадающем меню: это входы на посадочные
  страницы под низкочастотные запросы и внутренняя перелинковка, ради которой
  всё и затевается. Каждый раздел — ссылка со своим адресом.
- `.hero` с заголовком и абзацем нужен на каждой посадочной: это единственное
  место, где витрина отличается от кабинета закупщика — краулеру нужен текст,
  а не только таблица.
- Название «Блогеры России» и знак — заглушка: домен ещё не куплен. Витрина
  идёт не под брендом WOWBlogger (решение 01.07), поэтому марка своя.
- В любых пользовательских надписях **WOW пишется капсом** — требование
  заказчика. URL и технические строки не трогаем.
