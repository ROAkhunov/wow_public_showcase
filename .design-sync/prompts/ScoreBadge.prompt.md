Скоринговый бейдж: одна цифра у названия канала, по которой глаз сортирует выдачу, не читая метрик.

## Разметка

```html
<span class="score score--good">3,6</span>
<span class="score score--lg score--good">3,6</span>   <!-- крупный, на странице канала -->
```

Модификатор шкалы обязателен — без него бейдж прозрачный.

## Шкала

| Класс | Значение |
|---|---|
| `.score--good` | хорошо — приглушённый зелёный |
| `.score--mid` | средне — приглушённый охристый |
| `.score--low` | плохо — приглушённый кирпичный |
| `.score--none` | нет данных — серый, внутри прочерк `—` |

Размер: базовый 38×22 для строки выдачи, `.score--lg` — 52×30 для страницы канала.

## Правила

- Шкала намеренно приглушённая, не светофорная: на странице с сотней строк
  чистый красный и чистый зелёный дерутся за внимание с плашкой «реклама».
  Насыщенный цвет на витрине есть только в двух местах — этот бейдж и `AdFlag`.
- `.score--none` обязателен к использованию: часть каналов приедет без метрик,
  и пустое место в этой колонке ломает ряд.
- Цифры табличные, разряд один знак после запятой, разделитель — запятая.

## Открытый вопрос

Что именно показывает цифра — не решено. Форма есть, наполнение обсуждается
отдельно. Не придумывать расшифровку («рейтинг качества», «индекс доверия»)
и не подписывать бейдж: пока это просто число.
