Плашка «Реклама» и лента постов: рекламные посты помечены плашкой и тёплой левой гранью, под ними — раскрытие рекламодателя.

## Разметка

```html
<span class="flag">Реклама</span>
<span class="flag flag--solid">Реклама</span>   <!-- залитая, когда фон уже цветной -->

<div class="feed">
  <article class="post">
    <div class="post-head"><span class="post-date">24 июля</span></div>
    <p class="post-text">Текст поста.</p>
    <div class="post-stats">
      <span>Просмотров <b>48 210</b></span><span>Реакций <b>612</b></span>
    </div>
  </article>

  <article class="post post--ad">
    <div class="post-head">
      <span class="flag">Реклама</span>
      <span class="post-date">22 июля</span>
    </div>
    <p class="post-text">Текст рекламного поста.</p>
    <div class="post-stats">
      <span>Просмотров <b>61 004</b></span><span>Реакций <b>388</b></span>
    </div>
    <div class="adv-line">Рекламодатель: <b>ООО «Ромашка»</b> · ИНН 7707083893 · ОГРН 1027700132195</div>
  </article>
</div>
```

## Из чего состоит

| Класс | Что это |
|---|---|
| `.flag` | плашка: капсом, 11px, тёплая рамка и фон |
| `.flag--solid` | залитая версия |
| `.feed` | лента: колонка постов с зазором |
| `.post` | белая карточка поста |
| `.post--ad` | рекламный: тёплая левая грань 3px |
| `.post-head` / `.post-date` | шапка поста и дата |
| `.post-text` | текст поста |
| `.post-stats` | просмотры и реакции, числа в `<b>` |
| `.adv-line` | строка раскрытия рекламодателя, над ней разделитель |

## Правила

- Рекламный пост помечается плашкой **и** левой гранью, но не заливкой целиком:
  на ленте в сотню постов заливка превращает страницу в полосатый ковёр.
- Табов «все / только рекламные» не делать. Табов на витрине нет нигде
  (решение 27.07) — ни по постам, ни по площадкам.
- **Раскрытие рекламодателя (решение 28.07):** у юрлица выводим наименование,
  ИНН и ОГРН. У ИП — только ИНН и ОГРНИП, наименование не выводим вообще:
  в реестре оно и есть ФИО («ИП Иванов Иван Иванович»), а публиковать ФИО
  физлица нельзя.
- Плашка `.flag` — одно из двух мест на витрине с насыщенным цветом (второе —
  `ScoreBadge`). Не добавлять этот цвет никуда ещё.
