Фильтры каталога: скрываемая левая колонка с полями, строка поиска сверху и применённые фильтры тегами над выдачей.

## Разметка

```html
<div class="layout">
  <aside class="side">
    <div class="side-head"><b>Фильтры</b><button class="side-hide">Скрыть</button></div>

    <div class="group">
      <span class="ds-label">Площадка</span>
      <select class="field"><option>Все площадки</option></select>
    </div>

    <div class="group">
      <span class="ds-label">Подписчиков</span>
      <div class="pair">
        <input class="field" placeholder="от"><input class="field" placeholder="до">
      </div>
    </div>

    <div class="group">
      <label class="check"><input type="checkbox" checked> Только с метриками</label>
    </div>
  </aside>

  <div>
    <div class="topline">
      <button class="fbtn fbtn--on">Фильтры · 3</button>
      <input class="field search" placeholder="Поиск по названию канала">
    </div>
    <div class="applied">
      <span class="tag">Telegram <button>✕</button></span>
    </div>
    <!-- сюда идёт .list с .row -->
  </div>
</div>
```

Свёрнутое состояние — `<div class="layout layout--off">`: колонка фильтров
скрывается, выдача идёт во всю ширину.

## Из чего состоит

| Класс | Что это |
|---|---|
| `.layout` / `.layout--off` | сетка «колонка фильтров + выдача» / только выдача |
| `.side`, `.side-head`, `.side-hide` | панель фильтров, её шапка и кнопка «Скрыть» |
| `.group` | группа поля: лейбл `.ds-label` и контрол, разделены границей |
| `.field` | инпут и селект — одна форма на все поля ввода |
| `.pair` | два поля «от — до» рядом |
| `.check` | чекбокс с подписью |
| `.topline` | строка над выдачей: кнопка фильтров и поиск |
| `.fbtn` / `.fbtn--on` | кнопка; `--on` когда фильтры применены |
| `.search` | модификатор `.field`, растягивает поиск на остаток строки |
| `.applied` + `.tag` | применённые фильтры тегами, у каждого крестик |

## Правила

- Фильтры — в левой скрываемой колонке, разделы — сверху (решение 22.07, п.1
  T-41). Верхняя панель фильтров не масштабируется: параметров у витрины больше,
  чем влезает в строку.
- Применённые фильтры обязательно выносить тегами над выдачей и держать
  живыми. Это не украшение: живая фильтрация и сортировка — сигнал против
  «тонкой страницы», без неё каталог из шаблонных страниц читается поисковиком
  как масштабированный мусор.
- Фильтров по деньгам не бывает: цен на витрине нет.
