Шапка страницы канала: хлебные крошки, крупный аватар, название с площадкой и скорингом, описание, кнопки и ссылки на другие площадки автора.

```html

</div>

<div class="head">
  <div class="top">
```

## Из чего состоит

| Класс | Что это |
|---|---|
| `.breadcrumbs` | хлебные крошки над карточкой |
| `.head` | белая панель шапки |
| `.top` | аватар и текстовый блок рядом |
| `.ava.ava--lg` | аватар 72px (базовый `.ava` — 46px, для строки выдачи) |
| `.title` | название с иконкой площадки, галочкой и бейджем в один ряд |
| `.sub` | строка «площадка · тематика · @ник» |
| `.desc` | описание канала, не шире 62 символов |
| `.actions` + `.btn` | кнопки; `.btn--primary` — акцентная, `.btn--ghost` — с рамкой |
| `.sites` + `.sites-list` + `.chip` | другие площадки автора ссылками |
| `.chip .dot` | квадратик площадки внутри ссылки, цвет — классом `.plat--vk` и т.п. |
| `.updated` | дата обновления данных |

Крупные варианты элементов строки выдачи: `.ava--lg`, `.plat--lg`, `.ver--lg`,
`.score--lg`. Модификатор шкалы у бейджа всё равно обязателен.

## Правила

- Площадки автора — **ссылки на отдельные страницы, а не табы**: у каждого
  канала свой URL (решение 22.07, единица страницы — канал). Это же даёт
  кросс-ссылки, без которых SEO-каркас не работает. Табов на витрине нет нигде.
- Блока «это ваш канал» и формы заявки от владельца не делать: разбирать заявки
  некому (решение 22.07).
- Демографию аудитории не выводить (решение 22.07) и цен не показывать
  (решение 27.07).
- **WOW капсом** во всех пользовательских надписях — требование заказчика.
