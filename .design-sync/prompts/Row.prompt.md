Строка выдачи: аватар, название с иконкой площадки, скоринговый бейдж и четыре колонки метрик. Основной элемент каталога.

## Разметка

```html
<div class="list">
  <div class="row">
    <div class="ava">МТ</div>
    <div>
      <div class="name">
        <span class="plat plat--tg">TG</span>
        <a href="/channel/mirtrendov"><b>Мир трендов</b></a>
        <span class="ver">✓</span>
      </div>
      <div class="sub">Технологии · 218 постов за месяц</div>
    </div>
    <span class="score score--good">3,6</span>
    <div class="m"><span class="ds-label">Подписчиков</span><span class="ds-value">3 087 084</span></div>
    <div class="m"><span class="ds-label">Средний охват</span><span class="ds-value">57 146</span></div>
    <div class="m"><span class="ds-label">ER</span><span class="ds-value">1,84%</span></div>
    <div class="m"><span class="ds-label">Доля рекламы</span><span class="ds-value adv">7,4%</span></div>
  </div>
</div>
```

`.list` — обёртка списка, даёт рамку и скругление; `.row` внутри неё разделяются
границами, первая строка без верхней границы. Порядок колонок в гриде задан
жёстко: аватар, название, бейдж, четыре метрики.

## Из чего состоит

| Класс | Что это |
|---|---|
| `.list` | белая панель списка, границы вместо теней |
| `.row` | строка, грид на 7 колонок, минимальная высота `--row-h` (76px) |
| `.ava` | аватар 46px; без картинки — инициалы |
| `.name` + `.name b` | название канала, режется многоточием |
| `.sub` | вторая строка: тематика, число постов |
| `.plat` `.plat--tg` `--vk` `--yt` `--dz` | иконка площадки |
| `.ver` | галочка верификации |
| `.m` + `.ds-label` + `.ds-value` | блок метрики, см. `Metric` |
| `.score` | скоринговый бейдж, см. `ScoreBadge` |

## Состояния

- **нет метрики** — выводить явно: `<span class="ds-value none">нет данных</span>`.
  Пропускать метрику молчком нельзя: пустое место читается как поломка вёрстки,
  а без метрик приедет заметная часть каналов.
- **нет верификации** — просто не ставить `.ver`.
- **нет скоринга** — `.score score--none` с прочерком, а не пустая ячейка.
- **длинное название** — ничего делать не нужно, режется многоточием само.
  Переносить нельзя: строки в списке должны быть одной высоты, иначе колонки
  метрик перестают читаться как колонки.

Ниже 860px грид сам схлопывается до трёх колонок.

## Чего в строке нет

Денежных колонок — ни цены размещения, ни CPM, ни CPV (решение PO 27.07).
Это цены маркетплейсов-конкурентов. Демографии — тоже нет (решение 22.07).
