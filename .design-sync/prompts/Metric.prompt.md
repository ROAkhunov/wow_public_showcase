Блок метрики: мелкий серый лейбл капсом сверху, значение под ним. Работает и колонкой в строке выдачи, и плиткой на странице канала.

## Разметка

```html
<div class="m">
  <span class="ds-label">Средний охват</span>
  <span class="ds-value">57 146</span>
  <span class="sub">за 30 дней</span>   <!-- подпись необязательная -->
</div>
```

Три класса-раскладки:

```html
<div class="m-cols">…</div>    <!-- 4 равные колонки — в строке выдачи -->
<div class="m-tiles">…</div>   <!-- плитки от 150px, каждая в рамке — на странице канала -->
```

`.m` без обёртки — одиночная метрика где угодно.

## Из чего состоит

| Класс | Что это |
|---|---|
| `.m` | сам блок: колонка, лейбл над значением |
| `.ds-label` | лейбл — 11px, капсом, `--muted`, с разрядкой |
| `.ds-value` | значение — 14px, 600, табличные цифры |
| `.m .sub` | необязательная подпись под значением, 11px |
| `.m-cols` | четыре колонки |
| `.m-tiles` | плитки: белый фон, рамка, значение крупнее (`--fs-h3`) |

Цвет значения несёт смысл, а не украшает:

| Класс | Когда |
|---|---|
| `.adv` | доля рекламы — всегда этим цветом |
| `.up` / `.down` | рост и падение в подписи |
| `.none` | «нет данных» |

## Правила

- Табличные цифры включены в `.ds-value` — в колонке разряды не пляшут.
  Не заменять на свой шрифтовой стиль.
- Доля рекламы выводится посчитанным числом («7,4%»), а не «16 постов из 218»:
  считаем за пользователя (решение 22.07, п.4 T-41). Исходные числа уместны
  только подписью под значением.
- «Нет данных» выводить явно: `<span class="ds-value none">нет данных</span>`.
- Подпись под значением в строке выдачи не используется — только на странице
  канала, где она несёт то, что иначе стало бы отдельной метрикой.
- Денег в метриках нет: ни цен, ни CPM, ни CPV, ни себестоимости (решение 27.07).
