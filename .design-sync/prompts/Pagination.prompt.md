Пагинация и сортировка: панель сортировки над выдачей и постраничная навигация обычными ссылками.

## Разметка

```html
<div class="bar">
  <div class="sort">
    <span class="ds-label">Сортировка</span>
    <button class="sbtn on">По подписчикам</button>
    <button class="sbtn">По охвату</button>
    <button class="sbtn">По ER</button>
  </div>
  <span class="count">Найдено <b>24 615</b> каналов</span>
</div>

<div class="pg">
  <span class="off">←</span>
  <span class="on">1</span>
  <a href="?page=2">2</a><a href="?page=3">3</a>
  <span class="gap">…</span>
  <a href="?page=704">704</a>
  <a href="?page=2">→</a>
</div>
```

## Из чего состоит

| Класс | Что это |
|---|---|
| `.bar` | белая панель над выдачей |
| `.bar .count` | счётчик найденного, прижат вправо; число в `<b>` |
| `.sort` | группа кнопок сортировки |
| `.sbtn` / `.sbtn.on` | кнопка сортировки; `.on` — выбранная |
| `.pg` | ряд пагинации по центру |
| `.pg a` | доступная страница — **ссылка с адресом** |
| `.pg .on` | текущая страница, залита акцентом |
| `.pg .off` | недоступная стрелка на краю диапазона |
| `.pg .gap` | многоточие между диапазонами, без рамки |

## Правила

- Страницы — обычные `<a href>` с настоящим адресом, а не подгрузка по скроллу
  и не кнопка «Показать ещё»: краулер должен дойти до последней страницы.
- Соседние номера, первая и последняя страницы видны всегда. Иначе глубокие
  страницы недостижимы и по кликам, и по обходу.
- Текущая страница и недоступные стрелки — `<span>`, а не ссылка.
- Сортировка живая и по разным полям — это тот интерактив, который отличает
  каталог от статичного списка шаблонных страниц. Сортировки по цене нет:
  цен на витрине нет.
